Error Management Guide

Reference

1. Critical: গুরুতর সমস্যা। Production system-এ দ্রুত তদন্ত প্রয়োজন।

2. Error: কোনো request বা operation ব্যর্থ হয়েছে।

3. Warning: সম্ভাব্য সমস্যা বা অস্বাভাবিক আচরণ।

4. Info: সাধারণ তথ্যভিত্তিক event record।

Security: বাস্তব লগে কখনো password, OTP, API secret, access token বা payment credentials সংরক্ষণ করা উচিত নয়।

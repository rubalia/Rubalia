Expense Report

Business operating expenses

Expense data is not connected.
The currently provided Dashboard code does not include an expense-record API. No expense amount or expense category will be fabricated. Connect an authenticated expense API to display salaries, rent, marketing, hosting, delivery, administration and other business expenses.

Cash Flow Report

Actual cash received and paid

Cash flow data is not connected.
Order value does not confirm that money has been received. A verified payment, refund, withdrawal and expense ledger is required before cash inflow, cash outflow and net cash flow can be calculated.

Balance Sheet

Assets, liabilities and equity

Balance sheet data is not connected.
The current API information does not provide verified asset, liability and equity ledger balances. These values must come from a proper accounting ledger, not estimated from order or commission totals.
